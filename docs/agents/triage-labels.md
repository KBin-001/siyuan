# Triage labels

| Canonical role | Local status | Meaning |
| --- | --- | --- |
| needs-triage | needs-triage | Awaiting evaluation |
| needs-info | needs-info | Awaiting information |
| ready-for-agent | ready-for-agent | Specified and ready for agent implementation |
| ready-for-human | ready-for-human | Requires human implementation |
| wontfix | wontfix | Will not be implemented |

Use these strings for triage status in local specs and tickets. Execution states such as claimed and resolved follow the issue-tracker workflow.
