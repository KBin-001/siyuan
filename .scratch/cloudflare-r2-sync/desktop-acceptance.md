# R2 双电脑接入与验收

当前为自用 `v2` 分支的开发验证说明。02 的配置往返、持久化及原数据保留已通过自动化测试；实际 R2 和两个桌面客户端尚未验收。03 存在同秒并发编辑丢失版本的已复现缺陷，因此目前只适合使用可丢弃测试笔记验证流程，不能据此确认正式笔记安全。

## 准备

- 两台电脑都需要包含本次改动的客户端；官方发行版不包含本分支修改。本次没有构建、打包或发布客户端
- 先在第一台电脑用单独测试工作空间和测试桶验证；第二台电脑新建空工作空间，避免误把本地已有内容当成可覆盖的测试数据
- 在 Cloudflare R2 创建私有 Standard 桶，例如 `siyuan-personal-test`，保持公开访问关闭
- 为该桶创建 `Object Read & Write` 凭证，限定只访问该桶，保存 Access Key ID 和 Secret Access Key。无需账户管理员凭证或列出全部桶的权限；真实 R2 上的操作权限仍须以下流程验证
- 从桶详情复制 S3 API Endpoint。普通账户形如 `https://<ACCOUNT_ID>.r2.cloudflarestorage.com`；若控制台给出管辖区专用地址，原样使用该地址

以上参数来自 [R2 身份验证说明](https://developers.cloudflare.com/r2/api/tokens/) 和 [S3 接口说明](https://developers.cloudflare.com/r2/api/s3/api/)，核对日期为 2026-10-28。无需绑定自己的域名，也无需 Workers、公开桶地址或 CDN 代理。

## 第一台电脑

1. 在 `设置 - 同步` 选择 S3，在同步服务配置中填入下表参数并保存
2. 保留已有数据仓库密钥；若是全新测试工作空间，通过现有界面初始化密钥，并用现有导出操作单独保存恢复材料
3. 开启同步，先选择完全手动模式，确认目标为新建的测试桶后执行上传；看到同步成功后再继续
4. 建立两篇测试笔记并附上一张图片或小文件，再次上传；检查 R2 桶中出现加密仓库对象，不应直接看到笔记明文
5. 使用同步服务配置的导出操作保存 ZIP 配置包，并单独保存数据仓库密钥。配置包包含存储凭证，其现有编码不能当作可靠的密码保护，不要提交到 Git 或公开发送

| 字段 | 值 |
| --- | --- |
| Endpoint | 控制台提供的 S3 API Endpoint，不附加桶名 |
| Access Key | Access Key ID |
| Secret Key | Secret Access Key |
| Bucket | 私有测试桶名 |
| Region ID | `auto` |
| Addressing | `Path-style` |
| TLS Verify | `Verify` |
| Timeout / Concurrent Reqs | 先保留客户端默认值 |

## 第二台电脑

1. 使用同一开发版本，新建空测试工作空间，先保持同步关闭
2. 在 `设置 - 同步` 选择 S3，导入第一台电脑导出的 ZIP，或 ZIP 中原有的 JSON 文件
3. 核对桶名和 Endpoint；导入只设置存储连接参数，不包含数据仓库密钥，也不会替换已有密钥或自动开启同步
4. 在数据仓库密钥区域使用现有导入操作恢复第一台电脑的同一个密钥；不要新生成密钥替代它。已有正式数据的工作空间不要直接更换密钥，应另建测试工作空间
5. 开启同步并选择完全手动模式，第一次选择下载；确认笔记、图片和附件可打开。初次验证可把资源文件下载设为全部下载，以检查离线附件内容
6. 在第二台电脑新增一篇笔记并上传；回到第一台电脑下载，核对内容。此处通过才算真实 R2 双电脑手动同步闭环完成

配置包损坏或密钥错误时应报告失败，并保留本地笔记、原连接配置和恢复材料。不要通过删除仓库、清空桶或重新生成密钥处理错误。

## 自动同步与恢复验收

03 未完成前不把这些检查标为已验收。后续修复并验证冲突缺陷后，使用以下清单验收实际桌面生命周期。

- 两台电脑改为自动同步，保留生成冲突文档选项，核对同步间隔可见且可修改
- 第一台电脑编辑后等待成功，第二台电脑启动后确认收到；反向操作再检查一次
- 第一台电脑新增、修改、重命名和删除测试笔记及附件，等待同步完成，第二台电脑核对；另一方向重复
- 第二台电脑断网后编辑，确认本地内容仍在且同步显示失败；恢复网络后手动重试，等待成功，第一台电脑核对收到
- 暂停两边同步后离线修改同一篇测试笔记，再依次恢复同步，检查原文与冲突副本包含两个版本；尤其检查两次编辑的文件修改时间位于同一秒的情况
- 测试同步失败后重开客户端，确认原配置和密钥保留，重试后仍可恢复；重复同步不应改变内容或不断生成副本
- 两台电脑分别验证正常关闭客户端时的退出同步；未等到成功时不要在另一台电脑继续修改同一篇笔记
- 临时撤销测试桶凭证，确认显示失败并保留本地编辑；换回有效的受限凭证后重试，不更换数据仓库密钥

R2 使用既有调度同步，没有官方云同步感知所用的实时推送保证。切换电脑前仍应等待当前设备同步成功。
